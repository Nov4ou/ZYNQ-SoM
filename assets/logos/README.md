# Board silkscreen logo assets

Downloaded source logo assets for possible KiCad silkscreen import. Check trademark/use restrictions before production/commercial sale.

## Micron

- `micron-logo-black-tm-rgb.png` / `micron-logo-white-tm-rgb.png`: current official Micron PNG assets.
- `micron-black/micron-logo-black-r-cmyk.eps` / `micron-white/micron-logo-wht-r-cmyk.eps`: current official Micron EPS assets.
- `micron-legacy-2000-2024.svg`: older Micron wordmark commonly seen on Micron memory ICs before the 2024 rebrand; likely the best match for the chip-top marking.
- `micron-legacy-1987.svg`: much older Micron wordmark, kept only as a reference.
